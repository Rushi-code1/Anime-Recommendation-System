# 🍿 AniMatch — Machine Learning Anime Recommendation Engine

> A content-based and collaborative filtering recommendation engine that analyzes user preferences and anime metadata to deliver accurate, ranked viewing recommendations via an interactive Streamlit UI.

## 🚀 Features

- **Content-Based Filtering** — Computes TF-IDF vector representations of genres, themes, and synopses combined with cosine similarity scoring.
- **Top-N Recommendation Ranking** — Returns ranked recommendations with similarity scores, ratings, and member popularity.
- **Interactive Web App** — Built-in Streamlit app allowing real-time title search, dynamic similarity threshold tuning, and poster rendering.
- **Comprehensive Jupyter Analysis** — Full exploratory analysis, feature extraction, and model comparison notebook included.
